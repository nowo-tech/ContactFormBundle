Contact Form Bundle has been installed!

The Flex recipe:
  - registers NowoContactFormBundle
  - creates config/packages/nowo_contact_form.yaml
  - imports routes in config/routes/nowo_contact_form.yaml

Next steps:
1. Create the database schema (migration or doctrine:schema:update).
2. Protect admin routes in your own security.yaml (the recipe no longer ships a second access_control file:
   Symfony refuses two security.access_control lists), for example:
     security:
         access_control:
             - { path: ^/admin/contact-forms, roles: ROLE_ADMIN }
3. Keep security.allow_unauthenticated: false (refused in the prod environment since 1.6).
   Point nowo_ui_kit.layouts.admin / .guest at your layout.
4. Schedule GDPR cleanup: php bin/console nowo:contact-form:cleanup-submissions

See docs/INSTALLATION.md, docs/CONFIGURATION.md, and docs/SECURITY.md.
